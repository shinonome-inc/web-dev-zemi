# 9週目：本番デプロイ＆クラウド入門

## ゴール
- 本番環境に継続デプロイできる
- 環境変数・ドメインなど「本番ならでは」の要素を体験する

## Day1：本番デプロイ
- VercelまたはNetlifyなどで本番デプロイを行う
- 到達条件：公開URLでアプリにアクセスできる

## Day2：環境変数の管理
- APIキーなどの秘密情報を環境変数として安全に管理する
- 到達条件：コードに直接書かず、環境変数経由で値を読み込めている

## Day3：カスタムドメイン（任意）
- 任意でカスタムドメインを設定する
- 到達条件：（実施する場合）独自ドメインでアクセスできる

## Day4：クラウドストレージ超入門
- AWS S3またはGoogle Cloud Storageなどで、ファイルアップロードを触ってみる
- 到達条件：1つのファイルをアップロードして、URLからアクセスできた

## Day5：振り返り
- 環境変数・デプロイ手順をメモにまとめる
- 到達条件：「本番環境とは何が違うか」を自分の言葉で説明できる

## 進め方（AIの使い方）
- 「環境変数を安全に管理したい。やってはいけない例も含めて」
- 「S3（またはCloud Storage）に画像を置いて表示したい。手順と注意点を」
- 「デプロイ時のビルドエラーが出た。原因候補と確認順を教えて」

## よくある詰まりどころと回復手順
- 環境変数がローカルでは動くが本番で動かない → デプロイ先の環境変数設定が抜けていないか確認する
- APIキーを誤ってコードに書いてしまった → 即座にキーを再発行し、.gitignoreの設定を見直す
- アップロードしたファイルが表示されない → 公開権限（パーミッション）の設定を確認する

## 自己チェックリスト
> 各Dayの「到達条件」を満たしたら、その都度チェックしてOKです。

- [ ] 本番デプロイされたアプリにアクセスできる
- [ ] 秘密情報を環境変数で管理している
- [ ] クラウドストレージへのアップロードを1回以上試した
